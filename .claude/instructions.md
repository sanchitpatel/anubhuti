# Instructions for AI Coding Agents

All AI coding agents working on this repository must strictly adhere to the following rules:

1. **Surgical HTML Editing**: Perform surgical editing directly on the HTML files using file modification tools. Do not use custom scripts or automation scripts to write, edit, or regenerate HTML files.
2. **CSS Handling for Large Files**: To read, refer to, and edit CSS in large files, you are permitted to use Python scripts (or write temporary Python scripts) to parse, inspect, and modify the CSS rules efficiently and accurately.
3. **Explicit Prior Approval**: Before making *any* changes to files in the repository, you must first explain to the user exactly what changes you intend to make, show the proposed changes or a summary of them, and request and obtain the user's explicit approval. Do not modify any files without approval.
